# Высота

Интерактивный курс Samruk Business Academy по безопасности работ на высоте. В проект входят учебный маршрут, пять игровых станций, контроль знаний и пять глав визуальной новеллы с крупными планами снаряжения. Интерфейс и учебные материалы доступны на русском и казахском.

## Развёртывание на Vercel

1. Распакуйте архив и загрузите его содержимое в корень репозитория GitHub.
2. В Vercel выберите **Add New → Project**, подключите репозиторий и нажмите **Import**.
3. Оставьте корень проекта `./` и нажмите **Deploy**. Vercel возьмёт параметры сборки из `vercel.json`.

| Параметр | Значение |
| --- | --- |
| Framework Preset | Other |
| Node.js | 24.x |
| Build Command | `npm run build` |
| Output Directory | `dist` |

Прогресс хранится в браузере для адреса курса. Доступ к развёрнутому курсу можно ограничить настройками Deployment Protection в Vercel. [Развёртывание из Git](https://vercel.com/docs/git) · [Настройки Vercel](https://vercel.com/docs/project-configuration/vercel-json)

## Локальная проверка

Нужен Node.js 24.x. Для локального просмотра через команду ниже также нужен Python 3.

```bash
npm ci
npm test
npm run build
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Откройте [главную страницу](http://127.0.0.1:8000/) или [лекции](http://127.0.0.1:8000/#lectures).

## Структура проекта

- `web/` содержит приложение, учебные материалы, стили и иллюстрации.
- `scripts/` содержит сборку и тесты курса.
- `dist/` создаётся командой `npm run build`.
